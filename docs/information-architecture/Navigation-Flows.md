## NAVIGATION STRUCTURE (How users move)

### Primary Navigation (Navbar)
Users can jump to any section:
- Logo → Top of page (hero)
- Home → Hero
- About → About section
- Projects → Projects section
- Skills → Skills section
- Contact → Contact section

### Secondary Navigation (Within sections)
- Project cards → GitHub / Live demo (external)
- Social icons → GitHub, LinkedIn, Twitter (external)
- CTA buttons → Smooth scroll to next section
- Footer links → Quick navigation

### Mobile Navigation
- Hamburger menu (☰) appears on mobile
- Slides open from side
- Same navigation options
- Back button or click outside to close
